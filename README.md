# Universal File Merger

A desktop GUI application built with Python and Tkinter that allows users to merge PDF, Excel (`.xlsx`), PowerPoint (`.pptx`), and PNG image files into a single, unified PDF document.

## Features

- **Multi-Format Support:** Select and combine `.pdf`, `.xlsx`, `.pptx`, and `.png` files.
- **Easy-to-Use Interface:** Simple Tkinter GUI to manage your file queue.
- **Automated Processing:** Converts sheets, images, and slides into a clean layout before merging.
